# EECS 6412: Data Mining — York University

Graduate coursework and research project for **EECS 6412: Data Mining** at York University, taught by **Prof. Aijun An**. This repository contains implementations, experimental notebooks, reports, and coursework materials covering core data mining algorithms, preprocessing pipelines, classification benchmarks, and graph representation learning.

## 🔬 Coursework Highlights

### 1. Core Assignments
- **Assignment 1:** Implementation of fundamental data mining algorithms, feature processing, and algorithmic analysis (`a1q5_omkumar_patel.ipynb`, detailed PDF report included).
- **Assignment 2:** Comparative evaluation of classification and clustering benchmarks, model tuning, and evaluation metric assessments (`Data_Mining_A2_v3.ipynb`).

### 2. Group Research Project: GNN for Structured Problem Representation
- **Objective:** Investigating Graph Neural Networks (GNNs) to model relational and topological structures in complex tabular/graph datasets.
- **Key Contributions:**
  - Implemented end-to-end data preparation pipelines (handling null attributes, data cleaning, and node/edge mapping).
  - Constructed graph structures from relational problem descriptions to capture non-linear entity relationships.
  - Benchmarked graph embeddings and downstream predictive performance.

## 🚀 Getting Started

### Prerequisites
Clone this repository and set up a virtual environment:

```bash
git clone [https://github.com/PATELOM925/Data-Mining.git](https://github.com/PATELOM925/Data-Mining.git)
cd Data-Mining
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt  # or install jupyter, torch, and scikit-learn
```

### Running the Notebooks
Launch JupyterLab or Google Colab to run the experiments:

```bash
jupyter lab
```
